# luxo-site

Public website and release downloads for **Luxo**, a native macOS Git client.
Site: https://iamjason.github.io/luxo-site/

App source is private; signed and notarized builds are published under
[Releases](https://github.com/iamjason/luxo-site/releases). The download button
always points at the latest release. `tools/release.sh` in the app repo builds,
notarizes, uploads the zip here, and bumps the version label on this page.
